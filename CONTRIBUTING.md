# Contributing to FocusFlow

Thank you for your interest in contributing to FocusFlow! 

FocusFlow is an open-source screen recording tool that automatically transforms raw recordings into polished tutorial videos.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/<your-username>/FocusFlow.git
cd FocusFlow
```

3. Install dependencies.

```bash
pnpm install
```

4. Start the development environment.

```bash
pnpm tauri dev
```

## Ways to Contribute

You can help by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Fixing issues
* Improving the UI/UX
* Enhancing recording and export functionality
* Optimizing performance

## Submitting Changes

1. Create a new branch.

```bash
git checkout -b feature/my-feature
```

2. Make your changes.

3. Commit with a clear message.

```bash
git commit -m "Add feature: recording presets"
```

4. Push your branch.

```bash
git push origin feature/my-feature
```

5. Open a Pull Request.

## Guidelines

* Keep changes focused and well-scoped.
* Test your changes before submitting.
* Follow existing code style and project structure.
* Update documentation when necessary.

## Reporting Issues

If you find a bug, please open an issue and include:

* Steps to reproduce
* Expected behavior
* Actual behavior
* Screenshots or logs if applicable

## Questions

For questions, feature ideas, or discussions, please open a GitHub issue.
