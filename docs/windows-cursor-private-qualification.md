# Private Windows cursor/geometry qualification

This is a test-only candidate, not a production cursor producer or native PASS. Production Windows V2 remains WithCursor/embedded, with null pointerOrigin and cursorTiming. No native execution is authorized by this document.

The existing generated-native target has a separate `cursor-private` scope on `codex-windows-cursor-qualification`. Before cursor, DPI-context or fixture mutation, Python and Rust require a matching GitHub-hosted Windows run, repository, workflow/ref, SHA and run/attempt handshake. The runner also compares the actual checkout SHA. Review the exact workflow and native inputs before the one future invocation. Local desktop use is rejected. The private runner sends one checked pair of relative mouse-move events after placing the pointer inside its owned fixture to wake a suppressed hosted pointer. The positive disposable guard runs before these events. Original physical pointer position is restored on exit. No SetSystemCursor, theme change, click, keyboard or audio capture is present.

Private `Proof` owns the same gated WGC worker, Job, encoder, complete-cell selector and terminal clock checks, but never prepares an embedded manifest, calls the embedded Session arm/finish, publishes Completion or imports a project. Its seven proof subdirectories (`without`, `with`, `alpha-without`, `alpha-with`, `challenge`, `resize`, `closed`) contain `proof-with-cursor.mp4` or `proof-without-cursor.mp4`, scalar trace/summary, two capped raw PAM exemplars, and bounded cursor/native-raster PAMs. `capture.json`, `capture.windows-v2`, `project.json`, `screen.mp4` and `session.json` are forbidden throughout this proof layout. The core negative test rejects import without changing private media.

Startup uses one WGC item and one capture. Metadata callbacks discard pixels until the first matching ContentSize/texture dimensions freeze the media size within the existing two-second deadline; the allocation size can differ (for example 336x279 allocation and 322x272 media). Frozen callbacks remain discard-only while the parent prepares and the worker completes gates, exact encoder ownership and the private park. The early control reader observes EOF/Stop throughout; the parent-death park remains deliberately blocked before supervisor/writer deadlines and retains its 30-second negative-test escape. Writer/supervisor setup precedes ARM under the publication lock. Admission then rejects older native timestamps. No size difference establishes a pixel origin.

The bounded test-only `trace.startup` receipt records actual transition QPCs and counts. The independent checker requires the actual freeze/probe/prepared/gate2/encoder/gate4/park/supervisor/writer/ARM order, one item/start/cleanup, zero pre-arm copies/publications/proof writes, every source native timestamp and publication at or after admission, and epoch equal to the first accepted source. Frozen raw dimensions must agree with source events, geometry, both retained padded exemplars and the decoded stream; allocation is not media authority. These scalars never grant recording/import authority.

Before the future matrix, the guarded driver executes the existing app library lifecycle tests (11), Windows capture contract tests (11) and owned-feed tests (9) under Rust 1.89, requiring zero failures/ignored cases and named startup, queued EOF/Stop and Stop/Ack cases. These are portable policy tests executed on Windows, not native API proof. All three log/command pairs are packaged. It then collects the four exact profiles once each. A cleanly failed profile remains FAIL but collection may continue only after raw receipts confirm the exact parent, workers, encoders and owned source have exited. Missing/changed owner receipts, unobserved preparation or unconfirmed cleanup stop collection; any failed or missing profile makes the global private result FAIL. No retry is performed.

The future matrix runs popup and decorated stationary fixtures at requested client dimensions 320x240 and 641x359. Actual item/ContentSize/texture/raw/encoded dimensions are recorded; requested client size is never substituted for raw WGC size. Three native 16px fiducials are independently located in raw pixels and compared with three separate scoped-PMv2 ClientToScreen queries. Only one signed unit translation is accepted, with a matching measured window/DWM/client candidate; no fitted scale, border removal, size-based origin, DPI multiplication or frame-origin assumption is used. Odd dimensions are padded on the right/bottom once, and normalized positions divide by encoded dimensions.

Each of the four profiles runs stationary monochrome and partial-alpha WithCursor/WithoutCursor pairs, with three observations and two raw exemplars per proof. Both exemplars must differ by the observed asymmetric cursor, with exact raw placement, hotspot and the unchanged per-channel tolerance of 1. Alpha is selected by a source-owned command before arming the alpha pair and restored before the original challenge/close sequence; source actions remain checker truth only. The private command budget is 16 (13 actual commands). CopyIcon owns its copy; GetIconInfo owns its returned bitmaps even on injected failures; GetDIBits checks dimensions and complete top-down scan counts; DCs/bitmaps/icons have bounded guards. Each observation decodes fresh pixels. For raw color bitmaps, missing/all-zero alpha is explicitly unsupported. The owned CopyIcon is rendered by DrawIconEx into a zero-filled owned 32bpp DIB, GdiFlush completes the draw, and existing math::color converts that candidate premultiplied surface to straight RGBA. This representation is a hypothesis awaiting native validation. The exact Win32 conversion stage behind the prior half-strength alpha failure remains unknown. Independent DrawIconEx renders of the original borrowed cursor on black, white, checker and color backgrounds must agree within the unchanged per-channel tolerance of 1; every background is retained even on mismatch. The borrowed original is never destroyed by extraction. Actual WGC alpha pairs must also agree; a GDI pass alone cannot qualify this interpretation. Zero alpha is canonical, ambiguous alpha fails, and destination-dependent AND/XOR inversion is explicitly unsupported. The native lane includes 16 repetitions of invalid-copy, after-copy, after-GetIconInfo, after-mask-read, after-color-raster-allocation, after-color-draw/flush and native XOR rejection paths, comparing GDI/USER handle counts. Bounded `native-color-0.pam` through `native-color-11.pam` retain the zero-DIB native color bytes before conversion, even on alpha conversion failure: PAM channel order is RGBA, RGB remains premultiplied, and alpha is unchanged. `cursor-N.pam` remains the canonical straight candidate. These named diagnostics, the two alpha proof directories, and bounded source command/ack receipts are explicitly packaged without increasing any existing file or aggregate cap. An alpha fixture changes the native cursor shape; same-handle pixel identity is also a portable negative control.

The observer brackets geometry, CURSORINFO, physical position, hit ancestry/creator identity, owned image extraction and repeated native checks with QPC. The independent checker retains actual F/E/A/S, midpoint and bracket uncertainty; rejects negative, regressing, overwide and half-open-end straddles; and makes no physical latency claim. Duplicate microseconds coalesce deterministically with hidden/discontinuity precedence in the portable checks.

Equal polls cannot prove historical compositor geometry or uninterrupted HWND generation. This candidate therefore rejects **all telemetry**. It never resumes after stable polls, and fixture commands are only independent checker truth, never observer inputs. Native challenges include alpha transition, hidden cursor, owned partial occlusion, move-away/back, same-size movement, minimize/restore, resize and automatic source close. Outside/edge observations are saved separately. Video cutoff retains the current complete-cell behavior. The close check requires worker exit before manual Finish and reports WGC Closed versus administrative source-unavailable truthfully.

Explicit resize runs in its own fresh worker after the nine-control challenge is finished and before the independent closed worker starts. Its first write, immediate exact-child liveness bracket, actual unchanged-origin WindowRect growth (+2,+2), resize operation QPCs, matching rejected content delta and one geometry cutoff must agree. A cutoff during SetWindowPos is allowed; an earlier/equal-tick or unrelated +7-height transition fails. The worker must automatically exit within the existing two-second bound before Finish, with no manual Stop. Both raw exemplars and the movie use this worker's own frozen grid. Seven named worker/encoder pairs and independent exact-handle observations are mandatory for each successful profile (28 pairs across four); partial failed attempts retain cleanup checks for every actually started owner. The 45-second profile and 40-second source watchdogs, 16-command budget and 13 source actions are unchanged; no retry or tolerance is added.

Historical run 42455293580 passed its four old private checker replays, but decorated challenge cutoffs preceded explicit resize and rejected an intermediate +7 content-height change of unestablished cause. That run's 24 owner proofs remain historical evidence; they do not establish decorated explicit-resize attribution. Challenge results now report actual geometry/manual termination and which observations fit wholly before their cutoff. Later rejection observations remain retained without a claimed recorded interval or resize cause. Separate close evidence still distinguishes source-unavailable termination from a delivered WGC Closed callback. Offline checker/metadata success does not establish the new native gate.

Upload packaging names each proof artifact explicitly, caps PAM/media/trace/aggregate sizes, and fails on omitted decisive evidence or forbidden authority. Existing full and close-diagnostic lanes remain separate.

No aggregate Windows, production cursor or release qualification follows from this lane.
